' =====================================================
' USUARIOS
' =====================================================

Cliente --> FRONT
Empleado --> FRONT
Administrador --> FRONT

FRONT --> API : HTTPS / JSON

' =====================================================
' API A NEGOCIO
' =====================================================

API --> AUTH
API --> USERS
API --> CAT
API --> INV
API --> ORD
API --> HIST
API --> NAI

' =====================================================
' SEGURIDAD
' =====================================================

API --> SEC : valida token / rol
AUTH --> SEC
NAI --> SEC : valida entrada
AUD <-- SEC : eventos seguridad

' =====================================================
' SERVICIOS A REPOSITORIOS
' =====================================================

USERS --> RUSER
CAT --> RPROD
INV --> RINV
ORD --> RORD

HIST --> RORD : obtiene pedidos\nentregados
HIST --> RPROD : obtiene productos

NAI --> RUSER : preferencias
NAI --> RORD : resumen de compras ENTREGADAS\n(solo con consentimiento de historial, FASE 9C)
NAI --> RPROD : catálogo disponible
NAI --> RAI : conversaciones

AUD --> RAUD

' =====================================================
' IA
' =====================================================

NAI --> ALIM : datos de «Mi alimentación»\n(solo con consentimiento de perfil)
ALIM ..> EVAL : restricciones de PERFIL\n(unión con las de la consulta)
NAI --> EVAL : restricciones de la consulta;\nexcluir antes de Ollama y\nre-evaluar tarjetas
RPROD ..> EVAL : evalúa elegibles y\nre-evalúa al resolver tarjetas
NAI --> IAClient : contexto permitido\n(solo productos permitidos)
IAClient --> IA : HTTP local\nPOST /api/generate
IA --> IAClient : respuesta / error
IAClient --> NAI

' =====================================================
' BD
' =====================================================

RUSER --> DB
RPROD --> DB
RINV --> DB
RORD --> DB
RAI --> DB
RAUD --> DB

' =====================================================
' VARIABLES ENTORNO
' =====================================================

JWT ..> AUTH : secreto JWT
KEY ..> IAClient : configuración IA
CREDS ..> DB : conexión

note bottom of ENV
Los secretos nunca se almacenan
directamente en el código fuente.
end note

note right of NAI
Construye contexto usando únicamente:
• perfil autorizado (lista blanca: objetivo;
  sin condiciones médicas ni alergias)
• catálogo disponible
Consentimiento de compras entregadas: independiente
(FASE 9A); FASE 9C lo usa solo para ordenar por
relevancia en el backend (nunca se envía a Ollama).
Historial de consultas: fuera de alcance.
end note

note bottom of DB
PostgreSQL mantiene la persistencia
de usuarios, productos, inventario,
pedidos, conversaciones y auditoría.
end note

FRONT --> IMG : carga imágenes locales\n(solo WebP/PNG/JPG)
CAT ..> IMG : valida/lista rutas\n(PostgreSQL guarda solo imagen_url)
